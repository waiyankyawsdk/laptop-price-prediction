About the Project

A full-stack machine learning application for intelligent laptop price estimation using Regression-Based Machine Learning.

This project is a web application that demonstrates the power of data science and machine learning applied to a real-world problem: predicting the price of laptops based on their hardware specifications.

A Random Forest regression model is trained on a curated dataset of laptop listings, then served through a Flask API. The frontend provides an intuitive interface to submit specifications and receive instant price estimates.

⚙️ Backend

  • Python 3
  • Flask (web framework)
  • scikit-learn (ML pipeline)
  • pandas & numpy
  • matplotlib / seaborn

🎨 Frontend

  • HTML5 & Jinja2 templates
  • Bootstrap 5
  • Custom CSS Design System
  • Google Fonts (Inter, Outfit)
  • Vanilla JavaScript

📂 Project Structure

  • data/ — Raw laptop dataset (CSV)
  • notebooks/ — Jupyter notebooks for EDA & model dev
  • src/ — Flask app main.py and utility functions
  • static/ — CSS, images, and static assets
  • templates/ — Jinja2 HTML templates
  • models/ — Saved model and preprocessor pickle files
